## 一 先判断题目要求哪一种证据

| 类型 | 识别线索 | 正确的分析动作 | 本次例子 |
|---|---|---|---|
| 教材术语分类 | “这种功能称为”“属于什么” | 找操作对象和动词，再匹配最具体的术语 | 查询和增删改属于数据操纵 |
| 语言规则 | 声明、赋值、接口、输出 | 先判断能否编译，再判断运行结果 | List与ArrayList |
| 概念范围 | “版本管理是什么” | 比较对象、动作、覆盖范围；防止把工具等同于概念 | 记录与追踪版本变化 |
| 经验性知识 | “通常建议”“上限为”且不给计算材料 | 识别经验阈值，记住适用条件 | 环形复杂度常用阈值10 |
| 原理推断 | 抗干扰、传输、介质 | 先按工作原理分组，再比较组内差异 | 铜缆与光纤 |

每题先做四件事：圈出单选或多选；圈出“最、不、一定、通常”等限定；用一句话重述问题；为每个候选项写一个成立或不成立的理由。遇到陌生术语可以暂时标记，但不要把每道题都当成需要计算的题。

## 二 数据库管理系统的数据操纵功能

截图： [照片1](screenshots/20261005/1-Photo-1.jpg)。题干问查询、插入、修改、删除数据库中数据属于什么功能。截图显示本人选B管理功能，题库答案为C操纵功能；C可独立核验。

关键在“对数据做什么”，而不在软件名称带有“管理系统”。可以把数据库理解成表结构、表内数据、使用权限三个层面：定义表结构是数据定义，查询或修改表内数据是数据操纵，限制谁能操作是权限控制。

| 本题选项 | 为什么选或不选 |
|---|---|
| A 定义功能 | 主要描述结构的创建和变更，与题干的数据增删改查不同 |
| B 管理功能 | 是宽泛说法，不能替代本题要考的具体功能分类 |
| C 操纵功能 | 题干列举的动作直接指向它 |
| D 控制功能 | 本题没有描述授权、约束或并发控制等控制行为 |

常见教材把SQL写作DDL、DML、DCL，部分还单列DQL和TCL。SELECT在某些分类中单列为DQL，在另一些分类中属于DML。考试要先识别它问的是DBMS功能还是某套SQL分类。Oracle文档将SELECT归入DML，但对GRANT的分类又不同于常见教材的DCL划分，因此不要把一种产品文档的分组强行套到所有教材题上。[Oracle SQL语句分类](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/Types-of-SQL-Statements.html)

复测动作：口头区分“新增一列”“新增一行”“赋予读取权限”，每项说明对象和动作。

## 三 ArrayList实例与List接口

截图：[照片2](screenshots/20261005/2-Photo-2.jpg)。本人选C，题库答案B；B可独立核验。题干“类继承了List接口”应严谨地改成“类实现了List接口”。

```java
// 假设已导入java.util.List和java.util.ArrayList，各行独立判断。
ArrayList a = new Object();     // A：编译错误，Object引用不能直接赋给ArrayList变量
List b = new ArrayList();       // B：合法，接口类型引用指向实现类对象
ArrayList c = new List();       // C：编译错误，不能直接实例化接口
List d = new List();            // D：同样不能直接实例化接口
```

先看等号右边能否创建对象，再看该对象的类型能否赋给左边。左边是变量的声明类型，右边决定实际创建的对象类型。接口类型变量合法，直接写`new List()`不合法。匿名实现类属于另一种完整语法，不是这里的`new List()`。

截图对A的解释说它“实例化了一个ArrayList类的对象”，这与`new Object()`矛盾，应纠正为类型不兼容。不要因为答案选对就默认整段解析正确。现代代码通常写`List<String> names = new ArrayList<>();`，用泛型保留元素类型检查。[ArrayList声明](https://docs.oracle.com/en/java/javase/18/docs/api/java.base/java/util/ArrayList.html) · [JLS赋值转换](https://docs.oracle.com/javase/specs/jls/se21/html/jls-5.html#jls-5.2)

复测动作：画出“变量b → ArrayList对象”，再解释为什么`Object x = new ArrayList<>();`合法，却不能直接通过x调用`add`。

## 四 版本管理题的证据缺口

截图：[照片3](screenshots/20261005/3-Photo-3.jpg)。显示本人选D、题库答案A，但缺少题干和四个选项。当时截图只能记录“平台判错”；题干和选项已于2026-10-26从粉笔做题记录补全，见本节末。

版本管理关注产品、文档、代码等不同版本的记录、追踪和维护。Git是版本控制工具之一，版本管理也可能涉及发布版本、分支、基线和变更流程。备份能帮助恢复数据，但仅保留一个覆盖式副本，不能等同于完整的版本控制。[Git官方关于版本控制的说明](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control)

同类概念题可以比较三项：管理的对象是什么；要执行哪些动作；覆盖单一动作还是整个过程。不能采用“最长的选项必然正确”或“越全面越正确”的口诀，内容范围必须与问题一致。

**2026-10-26补证：**粉笔做题记录里找到了这道题（粉笔题号2270220，出处2019年国考银保监会计算机类第45题）。题干：“版本管理是对系统不同的版本进行（ ）的过程。”选项：A.标识与跟踪　B.标识变更　C.发布变更　D.控制变更。答案A已核实，你当时选D。解析：版本管理覆盖整个过程——给每个版本打标识、记录和追踪其变化；B、C、D都只是其中一个动作。完整条目见[粉笔计算机错题](03_粉笔计算机错题.md)。

## 五 环形复杂度的计算与阈值

截图：[照片4解析](screenshots/20261005/4-Photo-4.jpg)、[照片5题干](screenshots/20261005/5-Photo-5.jpg)。本人选A即3，题库答案C即10。此题问常用建议阈值，答案按该教材口径取10；题干“等于……是上限”的写法不够顺畅。

环形复杂度也称圈复杂度，用于描述控制流结构的复杂程度及独立路径数量。常见单个连通控制流图有`V(G) = E - N + 2`，其中E是边数、N是节点数。在适用的二分判断模型下，也可用“判断节点数加1”。多路分支、短路条件是否拆分，要按题目给出的控制流图或计数规则处理。

“V等于多少”需要图或代码；“通常建议不超过多少”考查经验性阈值。10不能从没有给出的E、N中算出来，也不是超过它程序就一定有错。NIST资料第2.5节讨论了原始阈值10，并说明在额外工程条件支持下也有采用15的情况。[NIST结构化测试资料，第35页即正文第15页](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication500-235.pdf#page=35)

也不要把V当成所有可能执行路径的数量。有循环时，执行路径可能无限多；V描述的是独立路径的维度。环形复杂度与算法时间复杂度、代码行数也不是同一个量。

复测动作：看到图就计数；看到阈值题就说明经验性质。诊断卷DIAG-09和DIAG-10分别检查这两种能力。

## 六 光纤抗电磁干扰

截图：[照片6](screenshots/20261005/6-Photo-6.jpg)。本题为多选，本人选AD，题库答案BD；BD可独立核验。

| 介质 | 传输方式 | 本题怎么判断 |
|---|---|---|
| 非屏蔽双绞线 | 铜导体传递电信号 | 绞合有助于抑制干扰，但不具备光纤介质的电磁干扰免疫特性 |
| 同轴电缆 | 导体传递电信号，带屏蔽结构 | 有屏蔽不等于完全免疫 |
| 单模光纤 | 光信号在光纤中传播 | 选B |
| 多模光纤 | 光信号在光纤中传播 | 选D |

先分“铜缆还是光纤”，再分“单模还是多模”。模式数主要关联传播和色散特性，不会让多模光纤突然变成电信号传输。具体速率和距离还依赖光模块、波长、标准和链路条件，不能死背“某种光纤永远只有一个距离”。

本题针对传输介质受外界电磁干扰的相对表现；光收发器仍可能受电噪声影响，光链路也可能受衰减、色散和连接损耗影响。Cisco资料明确区分了光纤介质和光收发器。[Cisco物理基础设施指南](https://www.cisco.com/c/en/us/td/docs/sanity/suman/CPwE-Physical-Infrastructure_Feb2023.html)

复测动作：把四个选项按物理原理分成两组，并说明“抗电磁干扰”不等于“没有任何信号损伤”。

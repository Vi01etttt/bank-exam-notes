## 一 做题方法（10分钟）

**多选逐项判断。** 四套模拟卷丢分最多的是多选漏选（卷一7、卷二9、卷三8道）。每个选项旁写“对/错”：能指出明确错误的才判错，挑不出毛病的就选上。不要凭感觉挑组合，不要觉得“选三个够了”就停。

**看清问法。** 题目问“错误的”“不属于”“不正确的”，先在草稿纸上写个“反”字再做（卷一M40、卷四D05都栽在这里）。

**计算写步骤。** 子网写二进制、页面置换画每一步的物理块、哈夫曼写每次合并。最常见的错误是“差一位、多数一个”：/22是10位主机位，不是11位；rear指向的那一格本身没有元素。

**时间分配。** 职业基本知识约45分钟65题，平均40秒一题。计算题超过1分半先蒙一个往后做，概念题会就秒选。

这些都是在两个以上来源里错过的，今天必须能脱口而出。

### 2.1 数据库

| 考点 | 记住这一句 |
|---|---|
| 三级模式 | 模式＝全局逻辑（1个）；外模式＝用户局部视图（多个）；内模式＝存储（1个）。外模式/模式映像→逻辑独立性；模式/内模式映像→物理独立性 |
| 数据模型三要素 | 数据结构、数据操作、完整性约束 |
| 视图 | 虚表，只存定义不存数据；能简化操作、保护数据；**不一定提高效率** |
| 备份 | 差异备份以上次**完全备份**为基点，恢复只需“完全＋最近一次差异”；增量备份才要逐次全用。恢复＝转储＋日志 |
| 事务异常 | 读到别人未提交的＝脏读；同一事务两次读同一数据结果不同＝不可重复读；读出新增的行＝幻读 |
| 隔离级别 | 读未提交什么都防不住；读已提交防脏读（Oracle默认）；可重复读再防不可重复读（**MySQL InnoDB默认**）；串行化全防 |
| 索引 | 加快查询，但占空间、拖慢增删改；区分度低的列不建；一张表可以有多个索引 |
| OLAP与OLTP | OLTP：存取款、转账等日常交易；OLAP：按时间、地区、产品等**多维分析**，面向决策。数据仓库面向主题、集成、**相对稳定**、反映历史 |
| DML/DDL | DML：SELECT、INSERT、UPDATE、DELETE；DDL：CREATE、ALTER、DROP；DCL：GRANT、REVOKE。授权写`GRANT SELECT ON 表 TO 用户` |
| 码与完整性 | 候选码是能唯一标识元组的**最小**属性组；“性别只能男或女”是用户定义完整性；空值判断用`IS NULL` |

### 2.2 操作系统

| 考点 | 记住这一句 |

| 进程状态 | 阻塞→就绪：等待的事件（如I/O）完成；就绪→运行：被调度；运行→就绪：时间片用完；运行→阻塞：请求I/O或资源 |
| 互斥与同步 | 竞争同一独占资源（打印机）＝互斥；按先后顺序协作＝同步 |
| 死锁四条件 | 互斥、请求和保持、**不可剥夺**、循环等待，四个都是 |
| 碎片 | 可变分区、段式→外部碎片；固定分区、页式→内部碎片。页式是**动态重定位** |

## 三 计算题公式（15分钟）

| 题型 | 公式和步骤 |
|---|---|
| 子网（给子网数） | 借n位，使2ⁿ≥子网数 |
| 子网（给主机数） | 主机位h，使2ʰ−2≥主机数；前缀＝32−h。/22→10位主机位→1022台；/23→510台；/24→254台 |
| 路由汇聚 | 写出变化那个字节的二进制，找最长公共前缀 |
| 进制 | 全部换成十进制再比；171₈＝1×64+7×8+1＝121 |
| 字符编码 | '0'＝48，'A'＝65，'a'＝97（小写＝大写+32）；国标码＝区位码转十六进制+2020H；机内码＝国标码+8080H |
| 点阵 | 一个汉字字节数＝行×列÷8；24×24＝72字节 |
| 页面置换 | 每一步画出物理块；装入空块也算缺页；FIFO有Belady异常；OPT淘汰最久不用的未来页 |
| 流水线 | k段、每段Δt、n条指令：(k+n−1)Δt；5段、100条、1ns→104ns |
| 环形复杂度 | V(G)＝E−N+2＝判定结点数+1＝平面区域数 |
| 关键路径 | 最长路径；关键活动的松弛时间为0 |
| 哈夫曼 | 每次取最小的两个合并；WPL＝合并出的结点之和 |
| 二叉树 | n₀＝n₂+1；二叉链表空指针n+1个 |
| 循环队列 | 长度＝(rear−front+m) mod m；队满(rear+1)%m＝front |
| 哈希线性探测 | 冲突就往后找下一个空位 |
| 最小生成树 | Kruskal：从小到大选边，成环就跳过 |
| 查找 | 顺序查找平均(n+1)/2；二分查找最多⌊log₂n⌋+1次 |
| 笛卡尔积 | 属性个数**相加**，元组个数**相乘** |
| 精确率与召回率 | 精确率＝TP/(TP+FP)；召回率＝TP/(TP+FN) |
| C宏 | 宏原样替换不加括号：`#define SQ(x) x*x`，`SQ(1+2)`＝1+2*1+2＝5 |

## 四 各模块高频速记（25分钟）

**数据库：** DBS包含DB和DBMS；1NF原子、2NF去部分依赖、3NF去传递依赖、BCNF决定因素都含码；3NF不一定是BCNF；E-R转关系在逻辑设计，建索引在物理设计；X锁可读可写；两段锁是可串行化的充分条件；B+树数据全在叶子、叶子相连适合范围查询；触发器由增删改自动触发；索引失效：对列用函数、`LIKE '%x'`、类型转换、不满足最左前缀。

**操作系统：** 五大管理（处理机、存储、设备、文件、作业），没有“信息管理”；实时系统重及时可靠；静态重定位在装入时、动态在执行时；32位寻址4GB；PV操作是低级通信。

**组成：** 存储程序控制（冯·诺依曼）；Cache用SRAM，主存用DRAM需要刷新；RAM断电丢失；RISC指令少、定长、寄存器多、便于流水线，复杂寻址是CISC；系统总线分数据、地址、控制；中断保护现场是为了能返回原程序；1GB＝2³⁰字节；ENIAC 1946年美国；四代：电子管、晶体管、中小规模集成电路、大规模集成电路。

**网络：** DNS域名→IP，ARP IP→MAC；ping用ICMP；OSPF链路状态、RIP距离矢量（最多15跳）、BGP路径向量；DNS查询UDP 53；HTTP状态码：301永久、302临时、401未认证、403禁止、404找不到、500服务器错误、503不可用；GET安全且幂等，POST不幂等；HTTPS用非对称交换密钥、对称加密传数据；单模光纤比多模传得远。

**数据结构：** 顺序表随机存取，链表插删方便；栈后进先出，深度优先用栈、广度优先用队列；入栈1、2、3不可能出栈3、1、2；快排平均O(n log n)、最坏O(n²)；Prim稠密图、Kruskal稀疏图；Dijkstra单源不能有负权，Floyd求所有顶点对。

**软工：** 软件危机催生软件工程；结构化设计面向数据流；需求说明书不写算法；四类维护：改正、适应、完善、预防；OO三特征：封装、继承、多态；Java重写访问权限不能缩小；Git：add进暂存区、commit进本地仓库、push推远程、pull＝fetch+merge；冒烟测试先测主流程。

**新技术与安全：** 物联网感知、网络、应用三层；VR生成虚拟场景，AR叠加现实；联邦学习数据不出域；大模型幻觉靠外部校验（RAG）；Transformer核心是自注意力；容器共享宿主内核、比虚拟机轻但隔离弱；K8s的Pod是最小调度单位；CAP最多同时满足两项、P必选；BASE追求最终一致性；监督学习有标签，聚类是无监督；区块链去中心化、不可篡改、可追溯；XSS注脚本、CSRF冒用登录身份、SQL注入用参数化查询防；数字证书由CA签发；病毒没有免疫性；数字人民币有法偿性、支持离线交易。

## 七 行测与英语（10分钟）

**资料分析：** 增长率＝(现期−基期)÷基期；基期＝现期÷(1+r)；增长量＝现期×r÷(1+r)，r＝1/n时≈现期÷(n+1)；比重上升看部分增速是否大于整体增速；间隔增长率＝r₁+r₂+r₁r₂。百分点和百分比不同。卡住超过2分钟就蒙一个往后走。

**判断推理：** 如果P则Q⇔如果非Q则非P；“只有P才Q”＝Q→P；“除非P否则Q”＝非P→Q。真假话先找矛盾，矛盾必一真一假。

**英语（在最后一个单元，约15题阅读）：**

- 给英语留至少15分钟。
- 先看题干、再回原文定位，主旨题最后做。
- 干扰项五个特征：绝对化（always、only、must）；偷换主体；硬加因果；程度或时态改变（may→will）；原词堆砌。
- 态度题偏中性的选项常对，cautious最常见，indifferent几乎不对。
- 转折词（however、yet、nevertheless）后面是重点。

详见[英语阅读考前突击](../2-topics/12_英语阅读考前突击.md)。

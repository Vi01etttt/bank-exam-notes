## 二 重大会议怎么考

**四中全会与十五五。** 四中全会审议的是规划“建议”；2026年3月12日，十四届全国人大四次会议批准规划“纲要”。前者提出方向，后者经法定程序形成国家规划。2035年是远景目标节点，不是十五五结束年份。依据：[S01 二十届四中全会公报](https://www3.xinhuanet.com/politics/20251023/777d21b244c4405c84b544d7cc43e236/c.html)；[S03 2026年政府工作报告](https://www1.xinhuanet.com/politics/20260313/9e24773bf14649f59afe2d62550e48ce/c.html)；[S04 十四届全国人大四次会议闭幕报道](https://www.mee.gov.cn/ywdt/szyw/202603/t20260312_1146449.shtml)

**中央经济工作会议。** 2025年12月会议部署下一年工作，政策组合是更加积极的财政政策、适度宽松的货币政策。八项重点任务涉及内需、创新、改革、开放、城乡区域协调、绿色转型、民生、风险防范。记主题之间的关系，不把“适度宽松”理解为不设条件地给所有企业放贷。依据：[S02 中央经济工作会议通稿](https://www.xinhuanet.com/politics/leaders/20251211/a583f835702d4dc2b8990ddee4644e92/c.html)

**2026年中央一号文件。** 聚焦农业农村现代化、乡村全面振兴；包含常态化精准帮扶、农民稳定增收等部署。银行场景可联系涉农融资和普惠服务，但这些场景是学习联想，不是文件新增的固定术语。依据：[S05 2026年中央一号文件发布](https://app.xinhuanet.com/news/article.html?articleId=00aaea55a11c6dc17de9182541c84cd2)

## 三 经济数字必须带上口径

下表前九项为2026年政府工作报告中的预期目标或安排，不是截至目前已经全部完成的实际结果。依据：[S03 2026年政府工作报告](https://www1.xinhuanet.com/politics/20260313/9e24773bf14649f59afe2d62550e48ce/c.html)

| 指标或安排 | 2026年口径 | 易混点 |
|---|---|---|
| 经济增长 | 4.5%—5%，实际工作努力争取更好结果 | 不能写成全年已增长5% |
| 城镇调查失业率 | 5.5%左右 | 与登记失业率不是同一指标 |
| 城镇新增就业 | 1200万人以上 | 保留“以上” |
| 居民消费价格涨幅 | 2%左右 | 是CPI相关目标，不是GDP增长 |
| 粮食产量 | 1.4万亿斤左右 | 与综合生产能力指标区分 |
| 单位GDP二氧化碳排放 | 降低3.8%左右 | 是强度指标，不是总排放量同比 |
| 赤字率 | 拟按4%左右安排 | 与经济增长目标区分 |
| 超长期特别国债 | 拟发行1.3万亿元 | 不是银行补资本专项金额 |
| 补充国有大型商业银行资本的特别国债 | 拟发行3000亿元 | 资金用途是补充资本 |
| 上半年GDP实际增速 | 4.7%，2026-07-16发布的解读口径 | 不能冒充全年结果 |
| 前三季度GDP初步核算增速 | 4.6%，2026-10-20发布 | 三季度单季是4.5% |
| 前三季度居民人均可支配收入增速 | 名义5.3%，实际4.4% | 实际增速已扣除价格因素 |

后三项依据：[S16 2026年上半年经济运行解读](https://www.stats.gov.cn/xxgk/jd/sjjd2020/202607/t20260716_1964139.html)；[S10 2026年三季度GDP初步核算](https://www.stats.gov.cn/sj/zxfb/202610/t20261020_1965658.html)；[S11 2026年前三季度居民收入和消费支出](https://www.stats.gov.cn/sj/zxfb/202610/t20261019_1965612.html)。GDP增速按不变价格计算；GDP绝对额按现价计算。统计数字可能修订，题目指定报告时，以指定报告的版本作答。前三季度数据不能直接推出全年结果。

## 四 银行岗位如何理解政策

金融“五篇大文章”是科技金融、绿色金融、普惠金融、养老金融、数字金融。2026年9月金融领域发布会继续围绕这些方向展开。这套分类不是2026年首次提出。依据：[S17 国新办发布会聚焦金融领域十五五工作重点](https://www.xinhuanet.com.cn/politics/20260910/5087a79deec045c18329e2ae05dbbc7f/c.html)

用业务对象记忆：科技企业研发与成果转化联想到科技金融；节能低碳项目联想到绿色金融；小微和涉农服务联想到普惠金融；养老需求联想到养老金融；数据与数字技术赋能服务联想到数字金融。这些是理解性例子，真实业务可以同时涉及多个方向，不能机械互斥分类。

央行2026年下半年工作会议继续强调适度宽松的货币政策，并涉及反洗钱、受益所有人信息备案、金融网络与数据安全、涉诈涉赌资金链治理等。科技岗可将这些要求对应到权限控制、数据保护、交易监测和审计留痕。后一组是技术实现联想，不是新增政策原文。依据：[S09 央行2026年下半年工作会议，广东省委金融办转载](https://www.gdjr.gov.cn/gdjr/jrzx/jryw/content/post_44383.html)

财政与货币政策要分清：特别国债是财政工具，央行降准降息是货币政策工具。银行补资本、向客户发放贷款、吸收客户存款是不同事项；“补充资本”不等于直接给居民账户发钱。依据：[S03 2026年政府工作报告](https://www1.xinhuanet.com/politics/20260313/9e24773bf14649f59afe2d62550e48ce/c.html)

## 五 开放合作与科技文体

**海南封关。** 2025年12月18日启动。“一线”连接海南与我国关境外，“二线”连接海南与内地；核心是针对货物流动等实施相应海关监管，不是禁止人员往来。具体税收优惠有条件，不能把“零关税”写成一切交易均免所有税。依据：[S06 海南自由贸易港正式启动全岛封关通告](https://www.12371.gov.cn/web/article/web/content_1451621233379180544.html)；[S07 海南封关政策解释](https://www.ccdi.gov.cn/yaowenn/202507/t20250723_436936.html)

**APEC中国年。** 2025年12月的非正式高官会确定2026年主题为“建设亚太共同体，促进共同繁荣”，三大优先合作领域是开放、创新、合作。第三十三次领导人非正式会议计划于2026年11月在深圳举行；截至本专题截止日尚未举行，不能编写其闭幕成果。依据：[S08 2026年APEC非正式高官会及全年安排](https://www.mfa.gov.cn/web/wjdt_674879/wjbxw_674885/202512/t20251212_11771512.shtml)

**福建舰。** 2025年11月5日入列，抓住舰名与电磁弹射特征；入列后仍需要试验验证和训练，不能推断入列当天所有实战能力均已形成。依据：[S13 海军新闻发言人就福建舰入列答记者问](https://www.mod.gov.cn/gfbw/qwfb/16420643.html)

**FAST。** 2026年9月25日迎来落成十周年，名称为500米口径球面射电望远镜。辨别射电望远镜与空间站、光学望远镜、导航卫星。依据：[S12 FAST落成十周年](https://www.xinhuanet.com/20260923/eab6eaddb23f496b8ccebdda73380803/c.html)

**十五运会。** 2025年11月9日在广州开幕，首次由粤港澳三地联合举办。举办区域和开幕城市是两个层级。依据：[S14 十五运会广州开幕](https://www.gwytb.gov.cn/m/headline/202511/t20251113_12734848.htm)

## 六 截止日和易错边界

2026年9月21日公布的安排是二十届五中全会于10月26日至29日在北京召开。截至2026-10-21，这是已公布的会议安排，不是已召开的会议，更不能引用尚未发布的全会公报。依据：[S15 二十届五中全会召开日期预告](https://www.xinhuanet.com/politics/20260921/f4717ffcaca041aca87806099ec0138e/c.html)

2025年9月的九三阅兵等事件早于本专题近一年窗口，可作为背景另行复习，不在本次事件清单中冒充窗口内事件。新闻页面更新日期也不能替代事件日期。

做题按四步：圈出年份和截止日；找准机构与文件；辨别目标、安排、初步统计和完成结果；最后检查“左右、以上、同比、环比、强度、总量”等限定词。复习先完成40题，把错题归入日期错、主体错、数字口径错或状态错，再回看相应来源。

### 1.2 利率框架"换锚"讲清楚

现在的政策利率是**7天期逆回购操作利率（1.4%）**，这是2024年起确立的。MLF从2025年3月起改为多重价位中标，**不再承担政策利率功能**。2026年的变化分两步：

- **政策利率要从7天换成隔夜。** 6月先试做隔夜操作，10月19日正式表态"研究择机切换"。这是调控框架改革，**不是降息**，短期对存贷款利率影响有限。
- **贷款定价从单一LPR走向LPR＋DR001。** DR001主要适用于财务实力强的大中型企业，由银企协商；**个人贷款（含房贷）和小微贷款继续参考LPR**。

易错点：

- "降准"是降低存款准备金率，释放的是银行可贷资金；"降息"是下调政策利率或LPR。2026年2月是降准，不是降息。
- PSL下调0.25个百分点是**结构性工具**利率调整，不等于LPR下调。
- 换锚之后LPR并没有被取消，房贷、小微贷款仍然看LPR。

### 1.3 数字人民币2.0（2026年1月1日起）

| 项目 | 2.0版规则 |
|---|---|
| 定性 | 从"数字现金"升级为"数字存款货币"，既带央行币串，又有商业银行负债属性 |
| 计息 | 一、二、三类（实名）钱包按活期存款挂牌利率计息；**四类钱包不计息** |
| 结息日 | 每年3月20日、6月20日、9月20日、12月20日 |
| 存款保险 | 余额纳入存款保险覆盖范围 |
| 准备金 | 银行类运营机构的钱包余额计入存款准备金交存基数；非银行支付机构按100%缴存保证金 |
| 运营体系 | 仍是"中央银行—运营机构"双层运营 |
| 规模 | 截至2025年12月末累计开立个人钱包2.3亿个 |

依据：[F08 数字人民币存款利息如何计算](https://www.news.cn/fortune/20260119/a5568ab569404a3c8ba8efd74d1ca9c3/c.html)

科技岗联想：双层运营对应"央行发行—运营机构兑换流通"的系统分层；钱包分级对应KYC强度与交易限额。这是理解性联想，不是文件原话。

## 二 金融监管、网络安全与立法

### 2.1 《关于银行业保险业人工智能安全开发应用的指导意见》（必背）

国家金融监督管理总局2026年6月18日发布，**8部分、32条**。

**四项原则**：谁使用谁负责、自主可控、务实高效、安全发展。

| 方面 | 必背要求 |
|---|---|
| 治理 | 建立需求分析、数据准备、训练开发、部署运行、维护迭代、评估退出的全生命周期管理 |
| 大模型 | 生成式AI模型实施准入管理；稳妥探索金融智能体 |
| 高风险应用 | 须经**本机构风险管理委员会**批准后方可实施；关键环节设人工监督干预和紧急停用条件 |
| 可解释性 | 可解释性不足的AI在高风险场景**仅能作为辅助工具，由人工最终决策** |
| 隐私 | 姓名、身份证号、手机号、银行卡号等个人信息不得用于生成式模型训练和优化 |
| 标识 | AI生成内容显著标识，并主动告知金融消费者 |
| 供应链 | 外包合作机构名单制管理；审查开源组件，防范供应链投毒 |
| 智能体 | 防范数据泄露、记忆污染、身份越权、工具滥用、运行失控 |
| 报告 | 面向公众或高风险场景使用生成式AI的，向金融监管总局或其派出机构报告 |

依据：[F09 指导意见全文要点](https://www.secrss.com/articles/91470)；[F10 人民网报道](http://finance.people.com.cn/n1/2026/0625/c1004-40747361.html)

记忆口诀："谁用谁负责，自主又务实，安全才发展；高风险要风委会批，说不清只能当助手，隐私不进训练集。"

### 2.2 网络安全法修正

- 2025年10月28日十四届全国人大常委会第十八次会议通过，**2026年1月1日起施行**（原法2017年6月1日施行）。

- 与《民法典》《个人信息保护法》衔接。

## 二 历史时间线及其含义

| 时间 | 发生了什么 | 应理解的变化 |
|---|---|---|
| 1954年10月1日 | 中国人民建设银行正式成立 | 最初承担国家基本建设资金拨付、管理和监督等任务，理解“建设”二字的历史来源 |
| 20世纪80年代中期起 | 陆续拓展居民储蓄、固定资产贷款、国际金融、住房贷款等业务 | 从原有职能向更丰富的商业银行服务转变；这是一个过程，不对应一个统一的“改制日” |
| 1994年 | 代行财政职能及政策性基本建设贷款业务分别移交财政部、国家开发银行 | 向现代商业银行转轨的重要节点，不等于当年更名或上市 |
| 1996年3月26日 | 中国人民建设银行更名为中国建设银行 | “人民”二字退出行名；不是更名为国家开发银行 |
| 2004年9月17日 | 中国建设银行股份有限公司成立 | 股份制改革的关键节点；此前已有50年历史 |
| 2005年10月27日 | H股在香港上市 | 境外资本市场节点 |
| 2007年9月25日 | A股在上海上市 | 境内资本市场节点 |
| 2018年 | 全面实施住房租赁、普惠金融、金融科技三大战略 | 记三项内容及服务对象，不把它与金融五篇大文章混在一起 |
| 2018年8月 | 正式推出劳动者港湾 | 网点资源向社会开放、提供便民公益服务 |
| 2018年12月 | 探索创建建行大学 | 金融教育和产教融合，不是面向高中生招生的普通本科大学 |

历史前三个阶段及更名日期依据[2004年债券发行公告的历史沿革部分](https://www.ccb.com/cn/ccbtoday/news/559607979100.html)；股份公司设立依据[建行50年历程回顾](https://www2.ccb.com/cn/ccbtoday/news/566442014100.html)及历年年报基本情况；上市日期依据[建行2007年度业绩公告](https://www.ccb.com/cn/ccbtoday/news/1207908089100.html)。2018年三大战略见[2018年度经营业绩公告](https://www.ccb.com/cn/ccbtoday/news/20190327_1553696966.html)；港湾与建行大学的启动月份见[建行官方回顾](https://m.ccb.com/chn/2021-03/24/article_2021082106160330436.shtml)。

**记忆串联：54成立，94转轨，96更名，04股改，05香港，07上海。** 这是自拟口诀，年份缩写不替代完整日期。

### 历史题常见陷阱

- 把前身成立、股份公司设立、上市三个不同事件写成同一年。
- 把“股份有限公司”中的股份制形式，误当作监管分类中的“全国性股份制商业银行”类别；建行通常归入大型商业银行。
- 把2004年的50周年与2005年的H股上市混成一件事。
- 把建行与国开行混为一谈：1994年的职能移交恰好说明两者是不同机构。
- 看到“率先”“首家”就扩大范围。若资料限定四大国有银行或大型商业银行，不能改成所有中国银行机构。

## 三 企业文化要分清层次和版本

### 当前复习主版本

以下按**2025年度报告企业文化页**核对。已下载港交所披露版本并渲染查看，位置为印刷第6页、PDF第9页。阅读原文可直接打开[本地年报文化页](ccb-resources/PDF/建行2025年度报告_港交所披露.pdf#page=9)；外部出处为[港交所披露原件](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0327/2026032702172_c.pdf)。

| 层次 | 应识别的表述 | 如何理解和区分 |
|---|---|---|
| 愿景 | 建设最具价值创造力的国际一流银行集团 | 回答希望成为什么样的机构；注意“价值创造力”“银行集团” |
| 核心价值观 | 诚实、公正、稳健、创造 | 回答办事与判断的基本价值标准；最后一词是“创造” |
| 经营理念 | 以市场为导向，以客户为中心 | 回答经营围绕什么展开 |
| 服务理念 | 客户至上，注重细节 | 回答服务时怎样对待客户和具体环节 |
| 合规理念 | 全员主动合规，合规创造价值 | 合规是全员职责，应进入业务流程 |
| 风险理念 | 稳健、审慎、全面、主动 | 不能理解为消灭一切风险，也不能变成只追求规模 |
| 创新理念 | 鼓励、开放、宽容、审慎 | 鼓励探索与风险边界并存，不能漏掉“审慎” |
| 人才理念 | 尊重人才，用好人才，留住人才 | 关注人才的使用和长期发展 |
| 作风 | 勤奋严谨，求真务实 | 回答日常怎样工作，不是愿景或核心价值观 |

**使命按四类对象理解：** 给客户更好的服务，给股东更大的价值，为员工提供发展的平台，对社会履行完整的企业公民责任。记忆顺序用“客户—股东—员工—社会”。需要逐字辨认时查看上方本地文化页，不把“只对股东负责”当成建行使命。

### 为什么网上会出现不同答案

[官网旧版文化页面](https://www.ccb.com/cn/ccbtoday/culture.html)仍能访问，其中愿景强调走在中国经济现代化前列、成为世界一流银行；风险理念强调了解客户、理解市场、全员参与、抓住关键；人才理念强调综合素质与业绩。它与近期年报的若干字段不同。

因此，遇到明确引用旧材料的历年题，先按题干年份判断；准备当前企业认知时优先使用2025年报这套已核验口径。不能把旧网页仍可打开，当成其中每个措辞都已同步更新的证明。本文不根据网页布局猜测具体修订年份。

### 宣传用语与行徽

“善建者行，成其久远”属于建行宣传用语，不能填到四项核心价值观中。其列示依据为[官网宣传用语栏目](https://www.ccb.com/cn/ccbtoday/culture.html)。

官方文章将行徽解释为从古铜钱演变的内方外圆图形，兼顾规范严谨与亲和融通；“建行蓝”也是其品牌识别线索。这里依据[建行官方品牌文章](https://www.ccb.com/cn/ccbtoday/news/20140318_1395123861.html)，不额外编造未经核实的颜色代码、几何比例或图形数量题答案。

### 文化情景题怎么判断

以下为基于文化要素设计的学习场景，不是建行内部制度原文。

| 情景 | 更合理的判断 | 关联知识 |
|---|---|---|
| 客户要求跳过身份核验以节省时间 | 解释要求并提供合规的便利安排，不能直接免除必要核验 | 服务与合规同时落实 |
| 为提高转化率而隐瞒产品限制 | 不应隐瞒，应真实说明适用条件与风险 | 诚实、公正、客户利益 |
| 新功能上线前发现授权漏洞 | 及时报告、评估和修复，按实际风险决定发布安排 | 主动风险管理与审慎创新 |
| 老年客户操作手机银行困难 | 耐心解释、提供适老服务，保护密码和验证码 | 客户至上、注重细节 |
| 认为风险由风控部门承担、开发只交付功能 | 业务、技术等岗位都要履行相应职责 | 全员主动合规 |

## 四 三大战略 五篇大文章 与常见品牌

### 三组概念不要串题

| 概念 | 内容 | 记忆方式 |
|---|---|---|
| 历史上的三大战略 | 住房租赁、普惠金融、金融科技 | 住房是生活场景，普惠是服务拓展，科技是支撑手段；此句为学习解释 |
| 金融五篇大文章 | 科技金融、绿色金融、普惠金融、养老金融、数字金融 | 可记“科技—绿色—普惠—养老—数字” |
| 三个能力 | 服务国家建设、防范金融风险、参与国际竞争 | 对应服务、风控、竞争三个方面 |

三大战略依据[2018年度经营业绩公告](https://www.ccb.com/cn/ccbtoday/news/20190327_1553696966.html)；五篇大文章与三个能力依据[当前投资者关系概况](https://www.ccb.com/chn/investor/indexv3.shtml)及2026半年报释义页。三大战略是历史战略表述，五篇大文章是当前金融重点，不能声称二者是同一清单或简单改了名字。

**科技金融与金融科技尤其要分开：** 前者侧重金融怎样支持科技企业和创新活动；后者侧重怎样运用技术改善金融服务与管理。这是概念辨析，不表示两者在实际项目中互斥。为集成电路企业设计融资方案，可以体现科技金融；改进银行反欺诈模型，可以体现金融科技应用。

五篇大文章也可以交叉。用数字平台服务小微客户，同时涉及普惠和数字；为绿色技术企业融资，也可能兼具科技和绿色。单选题应依据题干明确强调的主要目标，不要见到“APP”就排除其他维度。

### 品牌与服务对象对应表

| 名称 | 主要认知方向 | 常见误解 |
|---|---|---|
| 劳动者港湾 | 利用网点资源，为户外劳动者等有需要的公众提供便民公益服务 | 不等于贷款产品，也不意味着只能向建行存款客户开放 |
| 建行大学 | 金融教育、人才培养与产教融合 | 不直接等同于普通本科高校 |
| 建行惠懂你 | 面向普惠金融客户的综合服务平台 | 不宜写成面向所有客户的纯娱乐APP |
| 建融家园 | 与住房租赁服务场景联系紧密 | 不要与个人住房按揭贷款完全等同 |
| 裕农通 | 面向县域乡村的普惠服务网络和服务场景 | 不等于所有涉农贷款的统一产品名 |
| 手机银行与建行生活 | 构成建行常说的双子星平台；前者连接金融交易服务，后者连接生活消费等场景 | 双子星不是手机银行加惠懂你 |
| 建信金科 | 建信金融科技有限责任公司，建行集团旗下金融科技企业 | 不能把子公司简称当成建行总行部门名称 |

前四项的历史解释分别见[港湾与建行大学回顾](https://m.ccb.com/chn/2021-03/24/article_2021082106160330436.shtml)、[三大战略业绩说明](https://www.ccb.com/cn/ccbtoday/news/20190327_1553696966.html)；惠懂你和建信金科可检索[本地2026半年报](ccb-resources/PDF/建行2026半年度报告A股.pdf)；裕农通服务点的历史介绍见[2019年报](https://www.ccb.com/cn/investor/20200329_1585474539/20200330202651881643.pdf)，双子星配对见[2026年一季报](https://www2.ccb.com/chn/attachDir/2026/04/2026042919084537315.pdf)。产品功能和准入条件可能变化，这里只作品牌识别，不当作办理指南。

### 面向科技岗位怎么理解事件

**下面是学习推演，不是对建行内部系统实现的描述。** 支持科技企业融资，可以进一步联想到数据质量、企业画像和授信风险；跨境资金管理可以联想到多币种账务、权限、审计、可用性与一致性；生活服务平台可以联想到交易幂等、隐私保护与高并发。回答时先说已证实的业务事实，再说技术上可能需要考虑什么。

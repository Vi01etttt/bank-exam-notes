## 从这里开始

1. 先看[学习导航](notes/00_学习导航.md)第一节“现在该做什么”。
2. 主线是[建行科技岗笔试知识点讲义](notes/1-core/01_建行科技岗笔试知识点讲义.md)：考试结构、八大计算机模块、计算题附录、建行认知和时政。
3. 做模拟卷：[卷一](notes/4-mock-exams/04_建行信科岗计算机模拟卷一.md)、[卷二](notes/4-mock-exams/05_建行信科岗计算机模拟卷二.md)、[卷三](notes/4-mock-exams/06_建行信科岗计算机模拟卷三.md)、[卷四](notes/4-mock-exams/07_建行信科岗计算机模拟卷四.md)（知识面更广）。卷二、卷三按科技岗真实题量（40单选＋25多选，45分钟）编写。
4. 错题统一记在[错题集](notes/5-mistakes/00_错题总览与复习计划.md)：模拟卷一至三和粉笔共190道错题，每题都有题目、答案和解析。

## 离线阅读和验证

下载仓库后可直接阅读Markdown、图片和PDF；用浏览器打开 `notes/6-resources/past-papers/离线阅读入口.html` 可查看资料导航。

已安装Python时，在仓库根目录运行：

```powershell
python notes/6-resources/practice/检查SQL答案.py
python notes/6-resources/practice/检查Python读码.py
python notes/6-resources/practice/检查诊断卷.py
```

下载脚本会联网更新资料，日常阅读无需运行。少量扩展学习链接指向原Learning仓库，访问取决于该仓库权限。

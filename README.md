## 离线阅读和验证

下载仓库后可直接阅读Markdown、图片和PDF；用浏览器打开 `notes/past-papers/离线阅读入口.html` 可查看资料导航。GitHub手机端从本首页点击Markdown链接阅读；HTML离线入口需要下载后打开。

已安装Python时，在仓库根目录运行：

```powershell
python notes/practice/检查SQL答案.py
python notes/practice/检查Python读码.py
python notes/practice/检查诊断卷.py
```

下载脚本会联网更新资料，日常阅读无需运行。少量扩展学习链接指向原Learning仓库，访问取决于该仓库权限。

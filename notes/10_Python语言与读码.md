## 一 名字对象与容器

### 赋值引用与复制

Python变量名可以理解为绑定到对象的标签。`b=a`让两个名字指向同一个对象，不复制内容。若修改的是对象本身，两个名字都能观察到；若把某个名字重新绑定到新对象，另一个名字不随之改变。

列表、字典、集合通常可变；整数、字符串、元组本身不可变。元组不可变只表示其元素引用不能替换，它仍可引用一个可变列表。`a == b`比较值，`a is b`比较是否同一对象，判断None通常写 `x is None`。不要依赖整数或字符串驻留来推断is结果。

浅复制新建外层容器，内部元素引用仍可共享；深复制递归处理内部对象，但并非所有外部资源都能合理复制。复制的核心问题是“哪一层共享、哪一层独立”。参见 [Python复制文档](https://docs.python.org/3/library/copy.html)。

### 容器如何选择

| 对象 | 适合用途 | 常见陷阱 |
|---|---|---|
| list | 按位置维护一串数据 | `pop(0)`移动后续元素，队列更适合deque |
| tuple | 固定长度记录或不可变序列 | 可哈希还要求所有元素都可哈希 |
| dict | 按键查值、计数、分组 | 保持插入顺序不等于按键大小排序 |
| set | 去重与成员判断 | 不承诺按插入顺序或大小顺序遍历 |
| deque | 两端插入删除、队列 | 不能把它当作任意位置访问都O(1)的数组 |

字典的键和集合的元素需要可哈希。相等的可哈希对象必须有相同哈希值，哈希值相同却不代表对象相等；冲突后仍要比较键。内置list和dict不可作普通字典键。Python中True与1相等且哈希相同，因此不能把它们当成两个完全不同的字典键。规则见 [Python内置类型](https://docs.python.org/3/library/stdtypes.html)。

### 运算与复杂度边界

切片通常创建新序列，长度为k的列表切片有O(k)时间和空间成本；循环反复切大片数据会把看起来线性的算法变慢。`a.sort()`原地排序且返回None，`sorted(a)`返回新的列表。Python排序稳定，key函数表示排序依据，复合键元组按从左到右逐项比较。参见 [Python排序指南](https://docs.python.org/3/howto/sorting.html)。

`and`和`or`短路求值，返回某个操作数，不一定返回bool。例如空列表 `or` 默认列表，会选默认列表；若空列表本身是合法输入，这种兜底可能改变含义。除法 `/`产生真除法结果；整数 `//`向负无穷取整，例如 `-3//2=-2`，不能照搬其他语言向0截断的规则。

## 二 函数与作用域

### 参数绑定与可变默认值

调用函数时，形参绑定到实参对象。函数内 `items.append(x)`修改传入列表，调用方能看到；`items=[]`只把局部名字换到新对象。用“按共享对象传参”理解比简单背“传值或传引用”更稳妥。

默认参数在执行函数定义时求值，不是每次调用重新求值。需要每次新列表时，用默认值None并在函数体内创建。位置参数、关键字参数、`*args`和`**kwargs`解决调用形式；`*`后可限定仅关键字参数，不能把收集参数误解为拷贝所有内部对象。参见 [Python参数规则](https://docs.python.org/3/tutorial/controlflow.html#default-argument-values)。

### LEGB与闭包

名字通常按局部Local、外层函数Enclosing、模块Global、内置Builtins顺序查找。函数体里给名字赋值通常使其成为局部变量；在赋值前读它可能触发UnboundLocalError，而不是自动读外部同名变量。需要修改外层函数绑定时用nonlocal，修改模块绑定时用global；一般先考虑通过参数和返回值传递数据。

闭包保存的是对外层绑定的访问能力，循环创建函数不会自动冻结当时的变量值。默认参数或额外工厂函数可以在创建时保存所需值。参见 [Python执行模型](https://docs.python.org/3/reference/executionmodel.html)。

### 装饰器与递归

`@decorator`相当于定义函数后执行 `func = decorator(func)`。装饰器可以包裹日志、计时和校验，但是否继续调用原函数、返回什么，取决于装饰器实现。用functools.wraps保留被包装函数的名称等元信息，不能因此推断所有行为都保持不变。

递归需要终止条件和逐步接近终止的状态。Python一般不会自动把尾递归变成常数栈空间，深链遍历宜考虑显式栈；不要把提升递归上限当作算法复杂度优化。

## 三 迭代异常与资源

可迭代对象可以交给iter取得迭代器；迭代器通过next逐次产出元素，耗尽时抛StopIteration。列表可以多次创建新的迭代器，但同一个生成器对象通常只能消费一遍。函数含yield时，调用先创建生成器，函数体随迭代推进，yield暂停后保留执行位置和局部状态。参见 [Python类与迭代器教程](https://docs.python.org/3/tutorial/classes.html#iterators)。

异常处理分工：try放可能失败的代码，except处理明确异常，else在try正常完成后执行，finally在正常退出、异常或返回等常见离开路径做清理。不要在finally里随意return，它可能覆盖原返回值或压掉异常。with通过上下文管理协议安排进入和退出，退出逻辑是否抑制异常由管理器决定，不能一概说所有with都会吞异常。参见 [Python异常教程](https://docs.python.org/3/tutorial/errors.html)。

读取文件时明确编码，用with及时释放资源；文本的str与原始bytes是不同对象。JSON解析成功只能说明格式能解析，还要校验字段类型和业务范围。Python的bool是int子类，若接口严格要求“整数但不接受布尔值”，只用 `isinstance(x,int)` 不够，应补排除bool的条件。

## 四 类与面向对象

实例属性通常写在 `self.xxx` 上，每个实例可维护自己的值；类属性存放在类上，可被多个实例共同访问。类属性若是可变容器，在实例没有同名遮蔽属性时，对容器的原地修改会被其他实例看到。

实例方法通常接收self；classmethod接收cls，常用于与类相关的构造入口；staticmethod没有自动传入self或cls，适合放在类命名空间中的相关工具函数。Python访问成员主要靠约定与机制组合；前导单下划线提示内部使用，不提供强制访问控制。

继承中的方法查找按MRO进行，super沿MRO继续查找，不应简单记成“永远调用直接父类”。多态关键是共同的行为约定；运行时接受某个对象，不等于它一定满足正确的业务语义。类属性、方法与继承依据见 [Python类教程](https://docs.python.org/3/tutorial/classes.html)。

## 五 数值字符与输入输出

### 数值表示

二进制的第k位表示 `2^k`，一个十六进制位对应4个二进制位。n位无符号整数范围是0至 `2^n-1`；常见n位二进制补码有符号范围是 `-2^(n-1)` 至 `2^(n-1)-1`。最高位为1时，可用“无符号值减 `2^n`”解释该位串的补码值。例如8位 `11111011` 的无符号值251，补码值 `251-256=-5`。

Python的int不是固定32位整数，通常按需要扩展精度，受内存等资源限制。若题目指定8位或32位溢出模型，要按题设单独计算，不能把Python计算结果直接当成固定宽度机器结果。位操作 `&、|、^` 分别是按位与、或、异或；逻辑and/or处理真值与短路，二者不可混用。

许多十进制小数无法用有限二进制小数精确表示，因此 `0.1+0.2 == 0.3` 通常为False。近似科学计算可按误差要求用math.isclose；金额按业务选择整数分或Decimal，并明确舍入规则。Decimal应优先从十进制字符串构造，直接从float构造会保留那个float的近似值。参见 [Python浮点说明](https://docs.python.org/3/tutorial/floatingpoint.html) 与 [Decimal文档](https://docs.python.org/3/library/decimal.html)。

### 字符不等于字节

Python str保存Unicode文本；encode按指定编码转成bytes，decode反过来。UTF-8编码的一个Unicode码点占1至4字节，不是所有汉字或符号都固定同一宽度。`len(str)`数码点，也不一定等于人眼看到的字符数，因为组合符号和一些emoji由多个码点组成。`len(bytes)`数实际字节。参见 [Python Unicode指南](https://docs.python.org/3/howto/unicode.html)。

### 笔试输入输出

先读清输入是“一组数据”“第一行T组数”还是“读到EOF”。`split()`按空白拆分并忽略连续空白，`split(' ')`只按单个空格分隔，可能产生空字符串。批量读入再切分适合输入规模可放进内存的题；大文件或超大输入可逐行处理。输出只打印题目要求的数据，调试信息会影响判题。

建立二维列表时，每一行必须独立创建；`[[0]*m]*n`复制了同一行的引用。读取n个数时，要知道下一批token是否属于下一测试组；不能随意把剩余所有输入都当成本组。

## 六 线程进程与协程

线程共享进程内存，进程有更独立的地址空间；本章以asyncio为例，讨论协程在事件循环中的协作切换。并发是任务在时间上交错推进，并行是同一时刻实际执行多个任务。等待网络I/O的任务可用线程或异步I/O；纯Python CPU密集计算在常见启用GIL的CPython中，多个线程通常不能同时执行Python字节码，可考虑进程或会释放GIL的本地计算库。

这不是“Python所有版本都不能线程并行”：CPython自3.13起提供可选的free-threaded构建，具体能力取决于运行时和扩展。无论有无GIL，“检查后再修改”的复合业务操作都不能因此自动视为线程安全，应使用适当锁或原子机制。参见 [Python threading说明](https://docs.python.org/3/library/threading.html#gil-and-performance-considerations)。

调用async函数通常得到协程对象，不会因为调用了就自动完成执行；需要await或调度为任务。await可等待可等待对象；单纯把阻塞函数写进async函数，不会把它变成异步I/O。特别是事件循环线程中直接长时间计算或调用阻塞sleep，会拖住其他协程。asyncio锁保护协程间的相关共享状态，并不自动成为跨线程、跨进程的锁。参见 [Python协程与任务](https://docs.python.org/3/library/asyncio-task.html)。

## 七 十二道读码与辨析题

每段代码独立执行，不沿用上一题的变量。先写输出，再用“哪个名字指向哪个对象、何时执行哪行”解释。

### PY01 赋值浅复制与深复制

**题目：** 写出三个布尔值和最后两个列表。

```python
from copy import deepcopy
a = [[1], [2]]
b = a
c = a.copy()
d = deepcopy(a)
a[0].append(9)
print(a is b, a is c, a[0] is c[0])
print(c, d)
```

**答案：** 第一行 `True False True`；第二行 `[[1, 9], [2]] [[1], [2]]`。

**推理：** b和a同外层；c外层独立但内层列表与a共享；d内外层均在此次深复制中形成对应副本。append改了共享内层，所以c跟着变化。

**易错点：** 浅复制不等于“完全不复制”，也不等于“每一层都复制”。知识关联：对象引用与复制深度。

### PY02 可变默认参数

**题目：** 四次打印分别是什么？怎样使省略参数的每次调用用新列表？

```python
def add(x, values=[]):
    values.append(x)
    return values
print(add(1))
print(add(2))
print(add(3, []))
print(add(4))
```

**答案：** `[1]`、`[1, 2]`、`[3]`、`[1, 2, 4]`。

**推理：** 第1、2、4次省略values，使用函数定义时创建的同一列表；第3次传了独立列表。修正为 `values=None`，函数内 `if values is None: values=[]`。

**易错点：** `values = values or []`也会替换调用方明确传入的空列表，改变对象共享语义。知识关联：默认参数求值时机。

### PY03 闭包与创建时绑定

**题目：** 两行输出有什么不同？

```python
funcs = [lambda: i for i in range(3)]
fixed = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])
print([f() for f in fixed])
```

**答案：** `[2, 2, 2]` 与 `[0, 1, 2]`。

**推理：** 第一组函数在调用时读取共享外层绑定i，此时循环已结束且i为2。第二组每次创建函数时把当前i保存为各自的默认参数。

**易错点：** lambda不是特殊的“自动冻结变量”语法；普通嵌套函数也可能遇到同类问题。知识关联：闭包与默认参数。

### PY04 二维列表的共享行

**题目：** 修改第一行，为什么第二行也变了？

```python
bad = [[0] * 2] * 2
good = [[0] * 2 for _ in range(2)]
bad[0][0] = 9
good[0][0] = 9
print(bad)
print(good)
```

**答案：** `[[9, 0], [9, 0]]` 与 `[[9, 0], [0, 0]]`。

**推理：** bad外层有两个指向同一行对象的引用；good每次循环创建一个新行。将bad[0]整体重新赋值又会是另一种情况，因为那是在替换外层的一个引用。

**易错点：** 列表乘法复制元素引用，不能用来深复制嵌套容器。知识关联：对象别名、矩阵初始化。

### PY05 相等可变与可哈希多选

- A. 两个列表值相同，就一定是同一个对象
- B. 含有列表的元组不能直接作为普通dict的键
- C. True与1作为字典键会被视作相等的键
- D. 元组不可变，所以不能含有任何可变对象

**答案：B、C。** A混淆值相等与身份相同。B中的内层list不可哈希，阻止整个tuple被哈希。C由相等与哈希语义共同决定。D混淆“元组的引用不能替换”和“引用的对象不能改变”。

**易错点：** 可变与可哈希不是可对所有自定义类机械套用的同义词；本题针对列出的内置对象。知识关联：容器键与对象协议。

### PY06 生成器的消费顺序

```python
g = (x * x for x in range(3))
print(next(g))
print(list(g))
print(list(g))
```

**答案：** `0`、`[1, 4]`、`[]`。

**推理：** next已经消费第一个值；第一次list取走剩余值；第二次list遇到已耗尽的生成器，得到空列表。

**易错点：** 生成器节省的是不必一次保存所有产出，但多次遍历需要重新创建生成器或保存结果。知识关联：迭代协议与惰性计算。

### PY07 finally覆盖返回值

```python
def result():
    try:
        return 1
    finally:
        return 2
print(result())
```

**答案：** `2`。

**推理：** try准备返回1时仍需执行finally；finally发出的新return取代原返回动作。这是解释行为的反例，实际代码中清理资源通常不应在finally里返回。

**易错点：** 同样的写法还可能掩盖原异常；新版本解释器也可能对此给出警告。知识关联：控制流与资源清理。

### PY08 类属性与实例属性

```python
class Box:
    items = []
a, b = Box(), Box()
a.items.append('shared')
a.items = ['local']
print(a.items)
print(b.items)
```

**答案：** `['local']` 与 `['shared']`。

**推理：** 第一次通过a找到类上的items并修改它；第二次给a设置同名实例属性，遮蔽类属性；b仍查到类上的共享列表。若每个实例需要独立列表，应在初始化中设 `self.items=[]`。

**易错点：** 原地修改对象与重新绑定属性不是同一动作。知识关联：类与实例的属性查找。

### PY09 稳定排序与复合键

```python
rows = [('甲', 80, 18), ('乙', 90, 20), ('丙', 90, 20)]
ordered = sorted(rows, key=lambda row: (-row[1], row[2]))
print([row[0] for row in ordered])
print([row[0] for row in rows])
```

**答案：** `['乙', '丙', '甲']` 与 `['甲', '乙', '丙']`。

**推理：** 第一键负分数实现分数降序，第二键年龄升序；乙丙键完全相同，稳定性保留原相对顺序。sorted新建列表，rows原顺序不变。

**易错点：** 给整个元组排序加reverse，会把所有键方向一起反转，未必符合“分数降序、年龄升序”。知识关联：稳定性、原地与新建。

### PY10 补码浮点与字符编码

```python
from decimal import Decimal
print(int('11111011', 2) - 256)
print(0.1 + 0.2 == 0.3)
print(Decimal('0.1') + Decimal('0.2') == Decimal('0.3'))
print(len('中A'), len('中A'.encode('utf-8')))
```

**答案：** `-5`、`False`、`True`、`2 4`。

**推理：** 第一行按题设8位补码解读251；第二行包含二进制浮点近似；第三行从字符串准确构造十进制值；最后是2个码点，UTF-8中“中”3字节、A 1字节。

**易错点：** `int('11111011',2)`自身只会解析出251，不自动知道题目想用8位补码。知识关联：表示方式与解释规则。

### PY11 多组输入解析

**题目：** 输入第一项T=2，每组先给n再给n个整数。以下代码输出什么？

```python
raw = '2\n3\n10 20 30\n2\n-1 4\n'
tokens = iter(map(int, raw.split()))
t = next(tokens)
for _ in range(t):
    n = next(tokens)
    values = [next(tokens) for _ in range(n)]
    print(sum(values))
```

**答案：** `60`、`3`。

**推理：** 每组先消费长度，再恰好消费对应数量的元素。换行只是空白分隔，不影响token次序。输入承诺合法时按协议消费；若开发真实接口则应另行校验数据是否缺失或多余。

**易错点：** 把T当成第一组n，或把剩下所有数据都一次读成本组。知识关联：迭代器与输入协议。

### PY12 并发模型多选

- A. 在async函数中调用阻塞sleep，一定不会影响其他协程
- B. 常见启用GIL的CPython里，纯Python CPU密集任务通常不能靠多线程获得字节码多核并行
- C. GIL自动保证所有跨语句业务逻辑都是原子的
- D. 事件循环中的协作式并发也可能在await前后产生共享状态竞态

**答案：B、D。** A中的阻塞调用会占住事件循环线程；B有解释器与构建前提；C把解释器机制误认为完整业务锁；D表示先检查、await让出、再写入之间可能有其他任务改变状态。

**易错点：** 并发模型改变，不会让共享状态的不变量自动成立。知识关联：GIL、事件循环、同步边界。
